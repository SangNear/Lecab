# Vocab Master: AI-Powered Learning Platform

**VocabMaster** is a smart vocabulary-building web application designed to help language learners retain information long-term using a **Spaced Repetition System (SRS)** and **Generative AI**.

---

## ✨ Key Features
### 🧠 1. Spaced Repetition System (SRS)
The core engine of the app focuses on efficient memory retention:
- **Scheduled Reviews:** Every saved word is assigned a specific reviewDate based on your memory performance.
- **Daily Review Queue:** A focused dashboard that filters only the words due for review today.
- **Retention Tracking:** Tracks reviewCount and mastery levels to optimize the learning curve.

### 🤖 2. AI-Enhanced Learning
- **Auto-Generated Synonyms:** When adding a new word, the system automatically suggests relevant synonyms using AI to broaden your vocabulary.
- **Bilingual Context:** Generates English-Vietnamese narratives to help you understand words in a natural, story-based context.

## 🛠 Tech Stack

### Frontend (Client)
- **Framework:** Next.js 16 
- **Language:** TypeScript
- **State Management:** Redux Toolkit, RTK Query
- **Styling:** Tailwind CSS (Modern Glassmorphism & Bento Grid)

### Backend (Server)
- Runtime: Node.js
- Database: PostgreSQL
- ORM: Prisma
- Integration: Gemini API.
